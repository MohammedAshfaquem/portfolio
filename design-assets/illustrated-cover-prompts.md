# Illustrated project covers

Generated with the built-in image generation tool, using the two user-supplied images as visual style references. These are conceptual illustrations rather than product screenshots.

Shared art direction: landscape 16:9 product-mockup illustration; cream graph-paper background, muted sage panels, terracotta accents, silver desktop monitor and slim mobile device, soft studio shadows, floating circular line icons and connecting curves. Compact project title on the left, devices on the right. Minimal credible interfaces, generous margins, no slogans, designer claims or watermarks.

- Tickets2Me — Event & Movie Ticketing: event cards, cinema seat selection, booking summary and a mobile digital ticket. Supporting icons for inventory, counter sales and reporting.
- SmartDine — Restaurant Ordering: table tiles, order queue, kitchen status columns and mobile table QR ordering. Supporting icons for waiter service, kitchen preparation and reports.
- Food Rush — Food Commerce: food catalogue with burger, fries and wrap thumbnails, cart panel, mobile order summary and checkout status. Supporting icons for food, cart, payment and package orders.
